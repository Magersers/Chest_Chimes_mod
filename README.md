# Chest Chimes

Мод для **Minecraft Java 1.20.1 · Forge 47.4.0+ (47.x) · Java 17**.

Добавляет кнопку **♫** в заголовке открытого сундука. Через неё можно выбрать аудиофайл на компьютере, настроить слышимость и заменить звук открытия конкретного сундука.

## Возможности

- Обычные сундуки, сундуки-ловушки, двойные и эндер-сундуки.
- Системное окно выбора файла: **WAV PCM, OGG Vorbis, MP3**.
- Исходный файл: **не более 10 000 000 байт (10 МБ)**. Проверяются расширение, сигнатура и декодирование.
- Длительность: **0,1–5 секунд**. Используется начало файла; длинные записи обрезаются, короткие не дополняются тишиной.
- **«Только я»**: пользовательский звук слышит назначивший его игрок в радиусе 16 блоков. Остальные слышат стандартное открытие. Это действует и когда сундук открывает другой игрок.
- **«Все рядом»**: пользовательский звук слышат игроки того же измерения в радиусе 16 блоков, с затуханием по расстоянию.
- Повторное открытие во время звучания не создаёт второй экземпляр звука этого сундука.
- Предпрослушивание выбранного файла и кнопка восстановления стандартного звука.
- Настройки, UUID назначившего игрока и звук сохраняются в данных блока мира. После перезапуска исходный файл на компьютере не нужен.
- Русский и английский интерфейс. Громкость управляется настройками Minecraft «Блоки» и общей громкостью.

## Установка и использование

1. Установите Minecraft 1.20.1 и Forge 47.4.0 или новее в ветке 47.x.
2. Откройте [ветку builds с готовым JAR](https://github.com/Magersers/Chest_Chimes_mod/tree/builds) и скачайте **chest-chimes-1.0.0-all.jar** (кнопка Download raw file).
3. Поместите JAR в папку `mods`.
4. Для сетевой игры установите один и тот же JAR **на сервер и у всех игроков**.
5. Откройте сундук, нажмите **♫**, выберите файл, слышимость и длительность, затем **«Сохранить»**.
6. Закройте и снова откройте сундук, чтобы услышать результат.

Кнопка «Назад к сундуку» или Escape возвращает к инвентарю. При выборе нового файла прежние настройки сохраняются до успешной загрузки. «Вернуть стандартный звук» удаляет настройки и останавливает текущий пользовательский звук.

## Форматы и поведение

WAV: RIFF PCM, 8/16 бит, моно/стерео, 8–96 кГц. OGG: **Vorbis**, моно/стерео, 8–96 кГц (не Opus). MP3: декодирование JLayer, моно/стерео. Перед передачей файл преобразуется в PCM mono 16-bit 22050 Hz; максимальный фрагмент занимает 220 500 байт.

Настройка одна на физический сундук: любой игрок, которому разрешено открыть его инвентарь, может изменить её. В приватном режиме «я» — последний назначивший настройку игрок. Эндер-сундук настраивается по положению блока, а не по личному инвентарю. У двойного сундука обе половины используют общие настройки; после разделения настройки остаются у обеих половин. Звук закрытия остаётся стандартным. Одновременные звуки разных сундуков допустимы.

После сохранения на сервере хранится только выбранный фрагмент. Для увеличения ранее обрезанной длительности выберите исходный файл повторно. Предпрослушивание доступно для только что выбранного файла. Нестандартные контейнеры других модов, вагонетки с сундуком и бочки в эту версию не входят.

## Сборка

Нужен JDK 17; Gradle 8.8 скачивается автоматически через wrapper. В Windows используйте `gradlew.bat` вместо `./gradlew`:

```sh
./gradlew build
```

Готовый мод со встроенным декодером MP3: `build/libs/chest-chimes-1.0.0-all.jar`. Не устанавливайте одновременно обычный JAR и JAR с суффиксом `-all`.

```sh
./gradlew test
./gradlew runGameTestServer
./gradlew runClient
```

CI выполняет компиляцию, unit-тесты аудио/пакетов и GameTest на выделенном сервере, проверяет упаковку JAR и сохраняет его с SHA-256 в отдельной ветке `builds`. При заполненной квоте GitHub Artifacts JAR остаётся доступен в репозитории. CI не заменяет ручную проверку графического интерфейса, системного окна выбора файла и звука на реальных клиентах.

## Передача и ограничения

Сервер принимает изменения только для действительно открытого инвентаря сундука, проверяет расстояние, доступность блока, ID меню, порядок пакетов и длину PCM. Передача разбита на пакеты по 24 000 байт; клиент отправляет по одному пакету за тик. На игрока допускается одна загрузка одновременно и начало загрузки не чаще одного раза в 2 секунды. Незавершённые загрузки отменяются при закрытии сундука, выходе или тайм-ауте.

Звуки передаются слушателям при открытии; подавление повторов сокращает трафик при быстрых открытиях. Максимальный звук требует около 221 КБ на слушателя. Много разных настроенных сундуков увеличивает размер мира; аудио каждой половины двойного сундука сохраняется в её NBT.
