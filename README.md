# Chest Chimes

Мод для Minecraft Java Edition 1.20.1 / Forge 47.x / Java 17.

Индивидуальные звуки открытия сундуков: выбор файла на компьютере, режим «только я» или «все рядом», ограничение длительности до 5 секунд, импорт файлов до 10 МБ и восстановление стандартного звука.

Проект находится в разработке. Инструкции по сборке и установке будут добавлены вместе с реализацией.
