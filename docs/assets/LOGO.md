# Chest Chimes artwork

Generated using the built-in image generation tool, then manually finished with a deterministic Pillow raster-edit script: saturation 92%, contrast 106%, two inset rounded frame lines, Lanczos resizing and a mild 400px sharpening pass. No Minecraft texture assets were copied.

Prompt: Create a polished square app icon for Chest Chimes. An open wooden chest with a musical note and sound waves, warm wood and mint accents on deep teal, simple readable silhouette, no text or official game logo.

Final assets: chest-chimes-logo.png (1024px), chest-chimes-icon-400.png, chest-chimes-icon-128.png. The 400px icon is included in the mod JAR.
